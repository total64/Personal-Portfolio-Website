# Personal Portfolio Website

A simple static personal portfolio website containing pages for Home, About, Services, Rate, and Contact.

## Preview
- Open `home.html` (or any page) directly in your browser, or run a local static server for proper routing and consistent behavior.

Quick local server (Python):

```powershell
# From project root
python -m http.server 8000
# then open http://localhost:8000/home.html
```

## Project Structure

- about.html — About page
- contact.html — Contact page
- home.html — Home / landing page
- rate.html — Pricing / rate page
- service.html — Services page
- allcss/ — CSS files for each page
	- about.css
	- contact.css
	- home.css
	- rate.css
	- service.css
- images/ — images used by the site

## Notes
- This is a static site (HTML + CSS). No build step required.
- To publish, upload the folder contents to any static host (GitHub Pages, Netlify, Vercel, Surge, etc.).
